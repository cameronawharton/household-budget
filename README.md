# Household Budget

A shared Windows desktop budget app for the Wharton household. Pay periods, bill schedule, spending log and monthly budget, synced live between both computers through Supabase.

## Install

Download **Household Budget Setup 1.0.1.exe** from the [latest release](../../releases/latest), run it, and sign in.

Windows may show "Windows protected your PC" because the app isn't code-signed. Click **More info**, then **Run anyway**.

## Build from source

```
npm install
npm run dist
```
